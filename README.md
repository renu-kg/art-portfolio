A personal, production-ready art portfolio website built with pure HTML, CSS, and Vanilla JavaScript. Designed specifically to showcase fine pencil sketches and pen artworks with a modern, minimalist aesthetic.

👉 **[View Live Website](https://renu-art-portfolio.netlify.app)**

---

## ✨ Features

- 🖼️ **Pinterest-Style Masonry Grid** — Displays artworks in their natural aspect ratio without cropping, distortion, or forced square frames.
- 🔍 **Fullscreen Behance-Style Lightbox** — Displays high-resolution drawings with title, medium, year, category, and narrative descriptions. Supports keyboard navigation (`←`, `→`, `Esc`) and mobile touch swipes.
- 🌗 **Dark & Light Mode** — Seamless theme toggle with persistent user preference storage.
- 📱 **Fully Responsive Layout** — Optimized for mobile phones, tablets, and desktop displays.
- ⚡ **High Performance** — Native image lazy-loading, async decoding, zero framework overhead, and sub-second load times.
- 📩 **Integrated Contact Form** — Serverless form handling via Netlify Forms for instant email notifications.
- 📊 **Privacy-First Analytics** — Google Analytics 4 integration tracking page views and engagement without collecting PII.

---

## 🛠️ Technology Stack

- **Frontend:** Semantic HTML5, Vanilla CSS3 (Custom Properties & Flexbox/Grid), Modern Vanilla JavaScript (ES6+).
- **Typography:** Cormorant Garamond (Display/Headings) & Inter (Body).
- **Data Source:** Dynamic JSON fetching via `artworks.json`.
- **Hosting & CI/CD:** GitHub & Netlify Continuous Deployment.
